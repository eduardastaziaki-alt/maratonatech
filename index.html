Regras importantes

Uma denúncia por dispositivo

Para evitar abusos e denúncias falsas, só é permitido fazer 1 denúncia por usuário, por dispositivo.

Para derrubar uma conta

Uma conta só pode ser derrubada se receber 3 denúncias de usuários diferentes.

Como funciona?
1

Você envia o print e o link

Sua denúncia chega de forma anônima e é registrada no sistema.

2

Verificamos se é real

Nossa equipe analisa o conteúdo para verificar se não é um print manipulado ou uma informação falsa.

3

Conferimos na rede social

Entramos no perfil e verificamos se o usuário realmente fez o comentário, postou a foto ou cometeu a infração.

4

Tomamos as medidas

Se confirmado, o usuário é denunciado e pode ter sua conta suspensa ou derrubada (se receber 3 denúncias).
